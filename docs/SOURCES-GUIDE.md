# 资料来源准确度指南

本文说明 HIT VIDEO REPORTER 在各栏实际用过的来源：哪些比较准确、哪些不可靠或已经受阻、它们分别能证明什么、不能证明什么，以及建议的核验顺序。时间均为 Asia/Shanghai。本轮未做新的站外检索。

一条可上架的新卡，通常要同时核到：**官方原链、窗内发布日期、分视频热度（含采样时间）、真实封面、合法完整有声成片**。下面按平台写清：哪个来源能承担其中哪一项。

---

## 总原则

1. **第一手压过转述。** 官方帖、官方视频页、官方 RSS/接口、官方节展页，压过雷达、周报、精选镜像和综索引。
2. **出刊日、加入日、报道日、仪式日，都不是平台发布日。**
3. **合集播放、终身播放、综合「热度分」，都不是这一条在近窗口里的官方成绩。**
4. **第三方数字可以使用，但必须标明是第三方，并尽量回官方页复核。** 不能写成官方后台。
5. **已知受阻的路径记录一次就停**，换其他可达来源；不要换壳重试同一堵墙。
6. 没有专用的抖音 / 小红书 / 红果 / TikTok 官方搜索连接器时，不要把通用爬虫或登录态绕墙当成解决方案。

---

## 建议的总顺序

1. 官方原帖 / 官方视频页 / 官方频道 RSS / 官方节展页（日期、规则、第一手指标）。
2. 已安装且可用的官方接口（例如 X 的 `get_posts_by_ids` 一类按 id 取帖）。
3. 官方公开嵌入页（例如 Instagram embed）——可核对点赞等已展示字段，不代表能拿到完整播放文件。
4. 标明来源的公共档案库（例如 Reddit 的 arctic-shift）——分数要写成 archive。
5. 第三方索引或雷达（PicMany、glu.tv、DataEye、新榜、novelcatch、各类热播榜）——**只作线索**，用来发现 id 或封面方向。
6. 新闻报道、精选镜像、搜索摘要——只能帮助定位，不能单独过关。

某一步已经 412 / 503 / WAF / 403 / 登录墙，就记下缺口，改走下一步或申报 HOLD，不要重试。

## Instagram

| 来源 | 准确度 | 能证明 / 不能证明 |
| --- | --- | --- |
| 官方 `instagram.com` 帖页或 **official embed**（如 embed/captioned） | 较高，但是公开页常遇登录墙或软墙 | 可核短码、作者、部分可见的点赞等；不保证有播放数、分享数，也不保证能下到可审 mp4 |
| PicMany 等第三方成片/目录页 | **不可作为官方指标**；后来成片页多次 **HTTP 503**，目录里也曾一次出现 37 个 503，`haniverse_00` 还出现过 404 | 至多提供线索或当时抓到的第三方计数。必须标明 “PicMany third-party, not official IG dashboard”。503 后不要重试 |
| glu.tv 周榜 / shorts 列表 | 低（作日期时尤其低） | 可能提到作品名和作者，但通常**没有**官方 `instagram.com/reel/` 链接、官方时间戳或可下载成片。该站 “added” 日期不是上传日 |
| 公开网页搜索得到的 reel 短码 | 只是线索 | 看起来像新帖的短码，若核不到本窗口官方时间戳和过线指标，不能写成新合格候选 |

实务：没有官方 Instagram 公共搜索连接器。匿名发现经常被墙，多个批次只能 under-fill（+0 或仅封面 HOLD）。shares 常缺失，不要编造。电影人粉丝数也应尽量回到公开主页；PicMany 上的粉丝数只能当第三方参考。

## X

| 来源 | 准确度 | 能证明 / 不能证明 |
| --- | --- | --- |
| 官方 X 接口按 id 取帖（记录中的 `get_posts_by_ids` 一类） | **高**，应优先用于指标和 `created_at` | 能证明官方发布时间、播放、点赞、转发/引用等接口字段。转帖或后来再挂出的时间不是首发 |
| 创作者观察名单（watchlist）逐账号扫描 | **必要** | 能补上关键词搜索漏掉的、正文或字幕不含 “AI” 的爆款。2026-10-22 漏收 @JeffSynthesized Roadster 之后，成为每次更新的强制步骤 |
| 关键词搜索 | 中，易漏 | 只能覆盖命中关键词的帖，不能单独代表「X 栏已扫完」 |
| 评论区、截图、三方热帖列表 | 低 | 不能当官方数字或官方时间 |

封面用官方媒体预览即可。完整有声文件若已合法下载，才可做质量审。体裁限制（宣传小品、预告）必须按官方帖文和成片本身来写，不要从视频分析里擅自「发明」官方没有的片名或网址。

## Reddit

| 来源 | 准确度 | 能证明 / 不能证明 |
| --- | --- | --- |
| **arctic-shift** 公共档案 API | 可用，但必须**标明这是 archive score** | 能提供帖子 id、标题、作者、时间、档案库分数和评论数等。不是 Reddit 官方后台数字。采集后要标注来源与时间 |
| 官方 `reddit.com` JSON | 多次不可达或挂起 | 不能把「官方 JSON 失败」写成「没有新帖」 |
| 官方帖页上的 public preview / external-preview 图 | 可作封面线索 | 这是公开预览图，不是完整视频 |
| **v.redd.it 直接取媒体** | **已列为勿再请求** | 不能用来补「完整有声文件」。没有合法成片就保持 HOLD |

新卡宜在档案或官方分数 ≥500。软帖或 score <100 不得上架。AI 新闻/实验室类 sub 即使高分，也不进电影感成片栏；工艺向讨论可酌情进教程栏。覆盖不全时（部分 sub 422、超时）要写 limited，不要写成扫完为 0。

## YouTube

| 来源 | 准确度 | 能证明 / 不能证明 |
| --- | --- | --- |
| 官方频道 **Atom RSS**（`feeds/videos.xml?channel_id=`） | **高**，是后来最稳的批量发现路径 | 能证明官方发布时间、标题、频道和 RSS 当时给出的播放数。2026-11-22 对既有 987 个频道一次扫描全部成功（0 fail）。RSS 播放数要记下采样时刻 |
| 官方视频页 / 官方频道 | 高 | 用于核对上传者是否为真正官方源，以及说明、片长。不能代替本地完整有声审片 |
| yt-dlp 取元数据或封面 | 早期批次用过；**下载成片多次 HTTP 403** | 403 后不要重试，也不要用 player URL、内部接口、cookie 或非官方下载站去绕 |
| TubeAlfred 等未授权或仅元数据/字幕的连接器 | 不能当审片手段 | 字幕或摘要不是完整有声复核。`needsAuth` 时不要为了下片去登录 |
| YouTube Studio / Takeout / Premium 离线 | 官方说明只适用于**自己上传的视频**或 App 内离线播放 | **不能**合法导出他人公开视频为可交给审片工具的 mp4。这是能力缺口，不是「还没试」 |
| glu.tv 等「本月新片」列表 | 低（日期） | curator 的加入日 ≠ YouTube `upload_date`，未核官方上传日不得采用 |

务必核对官方频道：不要把转载号或名称相近的账号写成片源（见 Bone IV 的上传者纠正）。系列第 N 章、预告、工具测试、工厂目录剧集，即使播放过线，也不要自动当成新的独立短片。语言过滤不要误伤他加禄语里的 `hindi`。

## 抖音热门（电影感精片）

| 来源 | 准确度 | 能证明 / 不能证明 |
| --- | --- | --- |
| 官方 `douyin.com/video/{id}` | **应为规范来源** | 能证明官方链接；但公开抓取多次遇到 `byted_acrawler` 壳或 WAF，页内没有指标 |
| jingxuan（精选）镜像 | 早期用来核对过播放和封面，后来同样会出壳 | 可作线索或历史核验记录；**不要把精选镜像当成正式来源或新窗口的官方证明**。优先补回官方视频 URL |
| 公开网页/新闻索引 | 低 | 只能定位片名，不能代替官方时间和播放 |

播放必须是核验过的播放，不能只靠点赞。工厂装穷、萌宠梗、短剧教程即使高播也不进本栏。官方页受阻时写 blocked / limited，不要宣布「确认没有新片」。

## 最火 AI 短剧（抖音栏内子页）

| 来源 | 准确度 | 能证明 / 不能证明 |
| --- | --- | --- |
| 红果等官方日榜 / 可引用的近十日热度（记录中经 zongyimi 等整理的 Hongguo daily） | **相对最适合做近十日排序** | 能支持「近十日热度」徽章和排序。必须写清实际覆盖的日期范围。某几日榜尚未公布时，不要把旧窗改写成新窗 |
| 官方剧页、官方海报 | 高（封面与标题） | 封面必须是官方剧海报告，不要随机截屏、字幕静帧、占位图或错题图 |
| 报道/通讯里的终身播放、系列累计 | 只可作背景，并标明出处 | **不能冒充近 10 日热度** |
| DataEye 等剧集工厂数据库或播放增量 | 早期 v36 用过，随后按工艺标尺重做了榜单 | 可发现工业产量，但不是本栏要的 craft 标尺；不要用工厂剧集农场充数 |
| novelcatch、hongguoduanju.com 及其他非官方「AI 短剧热播榜」 | **不可作为官方证明** | 不是抖音或红果官方榜；综合分、「上线 N 天」、累计收藏都不能代替官方近 10 日成绩 |
| 雷达、新榜的转述播放 | 线索 | 必须回官方或注明未核。合集总播放不能写到单集上 |

《The Accident》《备用联系人》《万物生》《异邪录》《相骨》是工艺标尺。11/15–20 一类日榜尚未发布时，要暴露真实窗口（例如仍用 11/5–11/14），不要假装已经更新到今天。

## TikTok

| 来源 | 准确度 | 能证明 / 不能证明 |
| --- | --- | --- |
| 官方 `tiktok.com/@…/video/…` | 应为规范来源 | 官方页多次遇到 WAF 或地理墙，**受阻后不要绕过重试** |
| embed/v2 或 oEmbed | 中，早期首发填充用过 | 可核到部分公开元数据和封面；title/thumb 有时为空 |
| tikwm 等第三方指标页 | 第三方 | 可用但必须标明来源与时间；也曾 403。不要写成官方后台 |
| glu.tv 列表中的官方 TT 链接 | 链接或许可用，日期不可用 | “added” 不是发布日；仍要官方页指标 |
| 公开转载/再上传链 | 允许使用，但要诚实 | 不能把转载日写成原发日 |

从中国出口访问 www.tiktok.com 曾被 geo-wall。覆盖不全要写 incomplete，不能写成「已确认 +0」。首发窗口也曾不得不放宽（2026-09-08 起），因为严格 3 日窗口没有电影感过线片。

## Bilibili

| 来源 | 准确度 | 能证明 / 不能证明 |
| --- | --- | --- |
| 官方视频页 / 官方 view 接口 | 应为高 | 多次对重复命中返回 **HTTP 412**。同一批 id **试一次即停**，列入勿再请求 |
| 公开搜索 API（非 view 接口） | 有限 | 可发现候选和搜索页展示量，但搜索播放不是官方单片播放，覆盖会被 412 打断。0 条过线只说明「这一组搜索结果里没有」，不是全站没有 |
| 官方空间页 | 同属官方，但也可能 412 | 可用来确认作者 uid；空间 412 后不要重试 |
| 第三方雷达上的播放数 | 线索 | 雷达播放不能代替官方发布日期和官方单片播放。两集合计播放不能当成其中一集的播放 |
| 合集页上的大数字 | 易误用 | **不是**这一集的播放 |

没有官方日期和官方单片热度，即使有真实封面，也不能算 clear。版权向角色扮演、工厂漫剧，即使雷达数字高，也不进精选。

## 小红书（XHS）

| 来源 | 准确度 | 能证明 / 不能证明 |
| --- | --- | --- |
| 官方 `xiaohongshu.com/explore/{id}` | **规范链接** | 能作为原链。官方笔记页出现过 `error_code=300031`（暂时无法浏览）或跳到 404——这是访问/验证墙，**不能**据此写成已经确认删帖 |
| 登录后的浏览器扫视 | 有时才能看到赞藏 | 只读：不点赞、收藏、评论、关注或发帖。登录墙要如实写 incomplete，不要写成「扫完 0 条」 |
| note id 前 8 位十六进制转时间戳 | **只是启发式** | 推算落在窗外可以用来 HOLD；推算落在窗内也不能单独当作官方已确认发布时间 |
| 搜索卡上的赞数（有时会被页脚截断） | 低到中 | 与笔记页数字可能不一致，需标明来源 |

只要电影感短片，不要短剧/漫剧剧集或拆解教程。同一系列最多两张。没有专用官方发现连接器。

## 教程栏

来源主要是 YouTube、X、Instagram、Reddit，追加不覆盖。优先官方频道 RSS 和官方帖，筛选专业电影工艺，排除印地语入门「怎么做 AI 视频」、纯工具广告、带明显赞助 CTA 且未审的片子。Tutorials 不过成片播放门槛，但必须做语言和内容把关，并尽量完整听核；未听核要在卡上写明「待听核 / 未观看」，不能写质量通过。不要把同一条既当病毒成片又当教程重复上架。

## 顶尖 AI 电影人

| 来源 | 准确度 | 能证明 / 不能证明 |
| --- | --- | --- |
| 官方 Instagram 主页 / 代表作 reel | 高 | 粉丝、代表作链接、在做什么。要实际回看主页或新作，而不是只改目录日期 |
| PicMany 目录或计数 | 第三方，且后来大量 503 | 必须标明第三方；失败就保留旧卡和旧基线（例如 `haniverse_00` 404 时保留原卡，不删、不编新粉丝数） |
| 观察名单与 Junie 点名 | 高（作为「必须收录」的输入） | 仍要核粉丝和作品，不编造指标 |

目录新增不是自动的。`davidszauder` 等曾被明确不要自动加入。

## 电影节

| 来源 | 准确度 | 能证明 / 不能证明 |
| --- | --- | --- |
| **节展官方网站、官方规则、官方新闻稿** | **第一手，优先** | 截止日、时区、片长、提交资格、费用。时区未写就写「未标明」，不要为了保持「本周开放」去猜 |
| **FilmFreeway** 官方活动页 | 高，但若与官网冲突，以官网为准 | 例：Cine Prague 官网曾写延期至 11/18，FilmFreeway 另显示过 11/28——记录要求以官网 11/18 为准 |
| 官方日历 vs 页眉/页脚/旧文案 | 以能核到的正文为准，冲突就标待核 | AIIFF 出现过正文日期不一致（11/21 与 11/23 等），不能默认采用较晚日期 |
| 第三方「可投稿节展汇总」 | 线索 | 不能单独上卡 |
| 推荐日、论坛日、颁奖日 | 只能证明作品在那天之前已存在 | **不是**平台首发日，也常常早于当前新作窗口 |

每张征片卡应有片长（`runtimeZh` / `runtimeEn`）。官方规则确实没写，就写「未写明片长」，不要发明。范围：AI 电影节，以及明确接受 AI 影片的传统节，外加与 AI Movie Awards（AIMA）同量级的奖项。过期的开放状态必须按核对时刻改正，不能让已过截止的卡片继续显示「本周开放」。

## 明确不可靠或不要再撞的路径（汇总）

| 路径或例子 | 原因 |
| --- | --- |
| PicMany 成片/部分目录 | 第三方；后来多次 HTTP 503 |
| glu.tv 的 “added” / 本周收录日 | 站点说明那不是上传日；通常缺官方链和官方指标 |
| DataEye 工厂剧集增量 | 不是 craft 标尺，也不能冒充近十日官方热度 |
| 各类雷达、新榜、第三方热播榜 | 出刊日 ≠ 发布日；展示量须回官方复核 |
| novelcatch 等非官方 AI 短剧榜 | 不是红果/抖音官方榜，也不是近 10 日官方证明 |
| Bilibili 已 412 的视频页、空间或 view 接口 | 同一 id 不重试 |
| 抖音官方页 / 无 cookie 精选页的 acrawler 壳 | 直接取页路径不可用时不要换壳再撞 |
| TikTok 官方 WAF、已知 403 的 tikwm | 不绕过、不重试 |
| 官方 reddit.com JSON 失败、**v.redd.it** | 已记录；后者不能用来补完整视频 |
| yt-dlp 对第三方 YouTube 成片的 403，以及非官方「YouTube 下载站」 | 不合法或不被允许；官方也不提供他人视频的 mp4 导出 |
| 小红书 300031 / 跳转 404 | 不能写成已确认删除 |
| 只有标题的搜索摘要、未打开的官方页 | 不能写成已核验 |

## 各栏推荐核验顺序（短表）

1. **X**：观察名单 + 关键词 → 官方接口按 id 取指标和 `created_at` → 合法成片审片。
2. **YouTube / 教程**：官方频道 Atom RSS → 官方视频页核对上传者与说明 → 合法本地文件再审；不要用 yt-dlp 硬下他人成片。
3. **Reddit**：arctic-shift（标明 archive）→ 公开预览封面 → 完整文件若无法合法取得则 HOLD。
4. **Instagram / 电影人**：官方帖或 embed → 第三方索引只作线索；PicMany 503 停用。
5. **抖音精片**：已知官方视频 URL → 官方页指标；壳或 WAF 则 HOLD 并换线索，不重试。
6. **短剧**：官方/红果近十日榜（写清日期范围）+ 官方海报 + 官方视频或可核对剧页；终身播放和第三方热播榜降权。
7. **TikTok**：官方视频 URL → 公开 embed 或已标明的第三方计数；WAF 则 incomplete。
8. **Bilibili**：公开搜索只为发现 → 官方页/接口只试一次 → 412 改其他源。
9. **小红书**：官方 explore 链接 + 可见赞藏；启发式时间戳只用于排除，不用于过关。
10. **电影节**：官网规则页 → 必要时核对 FilmFreeway，冲突写明并以官网为准。
